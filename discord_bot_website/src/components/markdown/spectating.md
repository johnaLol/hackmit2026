# Spectating
\
\
Though this website is primarily for the authorization of the bot to your Discord server, observers can also spectate this ongoing event here as well.
\
\
If you hit the button at the bottom of the page, you can view a livestream of the Village Atlas world. All players are visible and move in real time! To navigate, use the arrow keys on your keyboard or press the control buttons built onto the page.
\
\
To prevent potential user overflow and avoid website latency spikes, you must create an account to spectate.
