# Description
\
\
Village Atlas began as an idea right before HackMIT, a large-scale hackathon hosted by the Massachusetts Institute of Technology, took off.
\
\
Created by Nicholas Rodriguez, software-engineering it using Python and constructing the database necessary, and John Giovanni, who built the web application that serves as a hub to integrate the bot into one's server, this bot aims to bring Discord communities together all day, every day.
\
\
This bot, a 2D top-down open-world game, was primarily inspired by sandboxes such as Minecraft.
